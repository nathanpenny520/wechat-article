# 安装与配置

面向首次安装的人。Agent 运行时的自检与配置细节见
[`wechat-article/references/01-setup.md`](../wechat-article/references/01-setup.md)。

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Python | **3.11+** |
| 必需依赖 | PyYAML、markdown、beautifulsoup4、cssutils、Pygments（排版必需）、requests（抓取与发布必需） |
| 可选依赖 | Pillow —— 图片压缩、按比例裁切、封面裁剪框、出图后检查。缺了会跳过这几步，不阻断排版与发布 |
| 微信凭证 | 仅发布需要 |
| 写作 / 画图模型 API Key | 可选，不配时由当前 Agent 直接写、直接画 |

## 2. 安装

```bash
cd wechat-article
bash install.sh
```

`install.sh` 会：

1. 在 `~/.wxarticle/venv` 建受管 venv 并安装依赖；
2. 把 `wxart` 命令装到 `~/.local/bin/`；
3. 把 skill 链接到 `~/.claude/skills/`、`~/.agents/skills/`（存在 `~/.codex`、`~/.openclaw` 时一并链接）；
4. 清理指向旧路径的**失效软链**（只删断链，不动有效链接）；
5. 跑 `wxart init` 生成配置模板与预设库，最后跑一次自检。

常用参数：`--no-venv`（跳过依赖安装）、`--no-link`（不链接）、`--no-clean-stale`（不清理断链）。

手动安装与 Windows 注意事项见 [`references/01-setup.md`](../wechat-article/references/01-setup.md)。

## 3. 自检

```bash
wxart doctor          # 人类可读；退出码 0 = 可继续
wxart doctor --json   # 结构化，Agent 用
wxart env             # 打印每一份实际读到的文件路径
```

缺 `style.yaml`、缺写作模型、缺画图模型、缺微信凭证都只是**提示**，不阻断写作、排版与配图。
只有 Python 版本过低和缺排版依赖是阻塞项。

## 4. 首次配置

`wxart init` 生成 `~/.wxarticle/config.yaml` 与 `.env`。要填的只有几项：

```yaml
article_category: ""   # 账号写什么领域
target_reader: ""      # 写给谁看
default_author: ""     # 默认署名
```

密钥只写 `~/.wxarticle/.env`：

```
WRITING_MODEL_API_KEY=      # 可选
IMAGE_MODEL_API_KEY=        # 可选；很多套餐不支持生图
WECHAT_1_APPID=             # 仅发布需要
WECHAT_1_APPSECRET=
```

**不要把密钥写进 `config.yaml`，也不要提交进 git。**

发布方式默认 `publish_method: draft`（只写草稿箱）。用户明确说「不接微信」时才设 `none`。

## 5. 装完确认

```bash
wxart themes                                # 18 套排版主题
wxart format --engine aws --list-themes     # 8 套模版 × 3 配色
wxart run start --topic "试一下" --mode draft --visual-mode none
wxart run show
```

## 6. 目录一览

```
~/.wxarticle/
├── config.yaml     账号配置        ├── presets/    预设库（7 类 + 8 模版 + 组件）
├── .env            密钥            ├── products/   业务资料库
├── style.yaml      写作风格        ├── exemplars/  范文库
├── history.yaml    历史与数据      ├── lessons/    修改学习
├── playbook.md     学到的规则      ├── themes/     学到的排版主题
├── runs/<run_id>/  每篇文章的产物   └── venv/       受管解释器
```

工作区里会出现一个 `.aws-article` **软链**指向 `~/.wxarticle/`（或项目覆盖层 `.wxarticle/`）。
它只是别名，不要往里面另存东西。想一个仓库对应一个公众号时，才建真实的 `.wxarticle/` 目录。

## 7. 排障

| 现象 | 处理 |
|---|---|
| `缺少运行依赖` | `wxart init`（建 venv 并装依赖）或 `pip3 install -r wechat-article/scripts/requirements.txt` |
| 命令找不到 | `~/.local/bin` 不在 PATH，加 `export PATH="$HOME/.local/bin:$PATH"` |
| 配置没生效 | `wxart env` 看 `config_dir` 与 `config_file`，确认读的是哪一份 |
| 排版报容器不相容（退出码 4） | 正文里的 `:::` 块与目标引擎不匹配，按报错的行号改写或换引擎 |
| 排版报产物未过门禁（退出码 5） | 产物里有微信会过滤的写法，换主题或修 HTML；确认无碍可加 `--no-check` |
| 生图退出码 1 | **跑错目录**或 API 报错；退出码 2 才是「未配置图片模型」 |
| 微信 40009 | 图片超过大小上限，装 Pillow 后会走自动压缩 |
| 想从旧版状态迁移 | `wxart migrate --dry-run` 预演，再 `wxart migrate` |

排障顺序：`wxart doctor` → `wxart env` → 本篇目录下的 `<环节>.log` → 对应阶段文档。

## 8. 卸载

```bash
rm -f ~/.local/bin/wxart
rm -f ~/.claude/skills/wechat-article ~/.agents/skills/wechat-article
rm -rf ~/.wxarticle          # 会一并删掉历史、范文库与业务资料库，先备份
```
